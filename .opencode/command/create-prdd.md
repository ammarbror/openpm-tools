# Create PRDD

Create one English PRDD (`PRDD - <Name> (EN)`) in the configured workspace (Notion by default; Obsidian only when `DOCUMENTS_PROVIDER=obsidian` or explicitly requested).

## Workflow

1. Read `.codex/skills/create-prdd/SKILL.md`, `docs/document-writing.md`, `docs/document-diagrams.md`, and `docs/notion-workflow.md` (when using Notion).
2. Inspect referenced source evidence first; ask only about missing decisions that materially change scope, business rules, or contracts.
3. Open with `## TL;DR` followed by the nine numbered sections in order, set `author` to the active user's profile (or `TBD`, never the AI/CLI tool name), eliminate all residual or filler wording, and validate diagrams and saved read-back.
