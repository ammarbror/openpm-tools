# Product & Technical Specification

Create, edit, or combine product/technical docs into one English specification (`Product & Technical Specification - <Name>`) in Notion (default) or Obsidian (`DOCUMENTS_PROVIDER=obsidian`). There is no CLI or MCP writer: use file, Notion MCP, and terminal tools, then verify what was saved.

## Workflow

1. Read `.codex/skills/product-technical-specification/SKILL.md`, `docs/document-writing.md`, `docs/document-diagrams.md`, and `docs/notion-workflow.md` (when using Notion) plus `notion://docs/enhanced-markdown-spec`.
2. Build an evidence map from referenced PRDs, code, schemas, and contracts before asking questions.
3. Open with `## TL;DR` followed by the twelve required headings in order plus `### Version History`, set `author` to the active user's profile (or `TBD`, never the AI/CLI tool name), eliminate all residual/filler wording, validate Mermaid diagrams, and verify saved read-back and single index entry.
