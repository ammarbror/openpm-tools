# Edit PRDD

Locate and update an existing English PRDD (`PRDD - <Name> (EN)`) in the configured workspace (Notion by default; Obsidian only when `DOCUMENTS_PROVIDER=obsidian` or explicitly requested).

## Workflow

1. Read `.codex/skills/edit-prdd/SKILL.md`, `docs/document-writing.md`, `docs/document-diagrams.md`, and `docs/notion-workflow.md` (when using Notion).
2. Read the complete existing PRDD before editing; stop and report if missing or locked rather than creating a replacement.
3. Ensure an opening `## TL;DR` precedes the nine numbered sections, harmonize all cross-section references, delete stale references and residual wording, preserve existing `author` unless changed (using active user profile for new entries, never the AI/CLI tool name), bump version + history, and verify read-back.
